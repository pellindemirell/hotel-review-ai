Playwright CLI & Yasal Uyarı

Terminal (Cursor):

pip install -r simulation/requirements-collector.txt
playwright install chromium

# Playwright — sayfayı siz açın, araç görünür yorumları okur
python simulation/collect_reviews.py --url "https://..." --platform tripadvisor --hotel "Rixos" --scroll --max 50

# Yapıştır modu
python simulation/collect_reviews.py --paste-file simulation/data/paste_example.txt --hotel "Rixos"

# Analiz ile birlikte
python simulation/collect_reviews.py --paste-file simulation/data/paste_example.txt --analyze --api-url http://127.0.0.1:8000

⚠ Yasal Uyarı: Booking.com ve TripAdvisor otomatik toplu kazıma yapmayın. Captcha bypass, proxy rotation veya bot koruması aşma desteklenmez. İzinli yöntemler: Google Places API, kendi otel sayfanız, manuel kopyala-yapıştır, açık veri setleri.
